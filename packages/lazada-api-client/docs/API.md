# Lazada API reference

> Generated by `npm run docs:api` from the built SDK. Do not edit by hand.

Every namespace hangs off a `LazadaModule` instance, e.g. `lazada.order.getOrder(...)`. Requests are signed (HMAC-SHA256), routed to the regional host from `countryCode`, time out after 30 s, and idempotent GET requests are retried on transient failures. Errors are thrown as `LazadaApiError`.
